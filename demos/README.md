# Demos - 单进程演示程序

本目录包含基于 OpenFHE 全同态加密库的独立单进程演示程序，无需 gRPC 网络通信即可运行，适合学习和验证同态加密核心算法。

## 子目录

| 目录 | 说明 |
|------|------|
| `three-party-average/` | 三方门限同态加密求平均值（CKKS 方案） |
| `threshold/` | 两方门限同态加密演示（CKKS 方案） |

## 与分布式系统的关系

这些单进程演示是 `distributed-system/` 中完整分布式系统的参考实现。分布式系统将这里的单进程逻辑拆分到多个进程并通过 gRPC 通信，实现了真正的网络化多方安全计算。

## 运行方式

进入对应子目录后：

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
./<可执行文件名>
```
